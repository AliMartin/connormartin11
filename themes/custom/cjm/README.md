# Connor Martin theme

[Bootstrap 5](https://www.drupal.org/project/bootstrap5) subtheme.

## Drupal compatibility

The theme declares Drupal 10.1 and Drupal 11 compatibility. Its Bootstrap5 base
theme must also support the target Drupal version; the project currently locks
Bootstrap5 4.0.8, which supports both versions. Stable9 is inherited through
Bootstrap5. Keep both base themes installed.

The theme uses CKEditor 5's `ckeditor5-stylesheets` declaration. Its settings
schema extends Drupal's `theme_settings` schema and describes the Bootstrap5
options and existing subtheme-generator values saved in `cjm.settings`.

Reviewed on 19 October 2026: Upgrade Status found no known issues; all three
Twig overrides compiled successfully, and active/default theme settings passed
schema validation. Four existing integer flags were normalized to booleans in
active configuration and the project-root `sync/cjm.settings.yml` export.
The homepage, an article, and a blog page returned HTTP 200 with the custom
layout and theme CSS; frontend and CKEditor CSS files also returned HTTP 200.
There are no custom JavaScript files or
executable PHP hooks in this subtheme. Existing templates, regions, CSS, and
library overrides are retained to preserve the site's appearance.

From the project root, rebuild caches and refresh the compatibility report:

```sh
ddev drush cache:rebuild
ddev drush upgrade_status:analyze cjm
```

When deploying these theme changes to another existing site, import the reviewed
`cjm.settings` export through the project's configuration workflow, or save the
theme settings after rebuilding caches to normalize their types with the new
schema. This project's configured sync directory still differs from the
project-root `sync/` export; reconcile that before running a configuration import.

After the local core upgrade, the settings schema, Twig compilation, and
homepage/article/blog/CSS HTTP checks also passed on Drupal 11.4.10. Before
production deployment, review sidebar layouts, interactive navigation, and
CKEditor 5 styling in a browser, including mobile widths. Stable9 is deprecated
in Drupal 11.4 but remains the Bootstrap5 base theme; plan its replacement before
a later major Drupal upgrade.

## Development.

### Maintenance page

`templates/layout/maintenance-page.html.twig` provides the dedicated motorsport
layout. Its `cjm/maintenance` library loads `css/maintenance.css` only on that
page; regular site pages retain their existing styling. This CSS is maintained
directly and is not generated by the Sass commands below.

The photograph in `images/maintenance-goodwood.jpeg` is a copy of the existing
Alfa Romeo image from the trackside journal, with no portrait of Connor. Keeping
it in the theme makes the maintenance layout independent of uploaded-file paths.
The message still comes from Drupal's maintenance settings; the matching export
is `sync/system.maintenance.yml`. Desktop and phone layouts were reviewed in
Chrome. The page retains Drupal's HTTP 503 maintenance response.

### CSS compilation.

Prerequisites: install [sass](https://sass-lang.com/install).

To compile, run from subtheme directory: `sass scss/style.scss css/style.css && sass scss/ck5style.scss css/ck5style.css`
